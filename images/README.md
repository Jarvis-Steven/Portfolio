# Local images

Add your own portrait here as `profile.jpg`. In index.html, replace the entire `div.portrait-placeholder` element with:

```html
<img src="images/profile.jpg" alt="Jarvis Steven J" width="600" height="648">
```

Use a real photo you have permission to publish. The reference image's sample person is not Jarvis and is not used as his portrait.

Add genuine project screenshots only when available. Use descriptive alt text explaining what each screenshot shows. The current CSS artwork is decorative and does not demonstrate project functionality.
