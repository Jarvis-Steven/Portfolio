Oceantrace AI

An AI-assisted marine monitoring project focused on detecting potential oil spills using satellite imagery and investigating possible vessel involvement through AIS data.

VITALGUARD

Prototype

VitalGuard

Open live demo ↗

A healthcare monitoring web application concept designed to help hospital staff monitor patients and identify persistent abnormal health patterns.

Project details

A prototype with Receptionist, Nurse, Doctor, and Admin dashboards for patient registration, staff assignment, vitals entry, rule-based risk assessment, and activity logs. The standalone demo uses fictional data stored in the visitor’s browser. Continuous monitoring and time-based alerts remain planned features.

Tools & skills
Flutter, Dart, Node.js, Express, MongoDB, and rule-based risk assessment. The standalone web demo uses browser-local storage with fictional data.
Contribution & learning
I contributed to designing the Reception, Nurse, and Doctor workflows and planning how patient information, monitoring dashboards, and alerts should connect. I learned about role-based interface design and communicating abnormal health patterns to healthcare staff. The project remains a prototype; reliable monitoring and alert delivery have not yet been established.

REIM

Concept

REIM

Explore hardware design ↗

A proposed offline environmental monitoring and early-warning system that combines local sensors, LoRa communication, and a gateway to help identify potentially hazardous conditions.

Project details

REIM’s proposed architecture uses ESP32-S3 sensor nodes to collect rainfall, water-level, soil-moisture, and tilt readings. LoRa communication connects these nodes to a Raspberry Pi gateway for local processing, event storage, and offline mapping. The design includes solar-powered operation, local safety-threshold analysis, and siren or beacon alerts. TinyML is planned to support analysis at the sensor nodes. These are intended capabilities of the design, rather than verified operational features.

Design Tools, Components & Skills
  • Microcontroller: ESP32-S3
  • Environmental sensors: Rainfall, water-level, soil-moisture, and tilt sensors
  • Communication: SX1262 LoRa radio and antenna
  • Gateway: Raspberry Pi with LoRa interface
  • Edge intelligence: TinyML and local safety-threshold analysis
  • Programming: C/C++ firmware and Python gateway processing
  • Mapping: Offline GIS and geospatial visualization
  • Power system: Solar panel, battery, charge controller, battery protection, and voltage regulator
  • Alerting and data storage: Local siren/beacon and offline event storage
Contribution & learning
My contribution focused on developing the system concept and hardware design, selecting proposed components, and planning how sensing, communication, power, and local alerts fit together. Through this work, I explored embedded systems, LoRa networking, offline data processing, and the practical requirements of environmental monitoring.
